**Hi, I'm Carles Sentis, a senior mobile engineer in Sitges, near Barcelona.**
From my first Amstrad 8256 to today's phones, building software has been the constant. By day I build Android and iOS apps for clients. In my own time I make the apps below, publish them on Google Play, and run the servers behind them myself.

🌐 [codeskraps.com](https://codeskraps.com) · ✉️ [apps@codeskraps.com](mailto:apps@codeskraps.com) · 🗂️ Most of my code lives on my own Gogs: [git.codeskraps.com](https://git.codeskraps.com/codeskraps)
